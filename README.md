# Список задач (To-Do List)

Современное веб-приложение для управления задачами с кастомным календарем, уведомлениями и сохранением данных.

🔗 [Посмотреть живое демо](https://romankitaev526-prog.github.io/todo-list/)

## Функционал
- Добавление задач с прикреплением даты и времени.
- Отметка выполнения (с анимацией зачеркивания).
- Удаление задач.
- Кастомный календарь для выбора даты и времени через выпадающие списки.
- Всплывающие и системные уведомления.
- Прерывистый звуковой сигнал при наступлении времени (с кнопкой «Остановить»).
- Подсветка просроченных задач.
- Массовое удаление (все выполненные или все задачи).
- Сохранение данных в localStorage.
- Фильтрация: Все / В процессе / Готово.
- Адаптивный современный дизайн (Glassmorphism, градиенты).

## Стек технологий
- HTML5
- CSS3 (Flexbox, Animations)
- Vanilla JavaScript (ES6+, Web Audio API)
- LocalStorage API
- Notification API

## Запуск локально
Просто откройте файл index.html в любом браузере.

При разработке использовал DeepSeek (модель R1/V3) для генерации базовой структуры приложения, логики на JavaScript и CSS-стилей. Доработка edge-cases, интеграция Web Audio API, настройка Git/GitHub Pages и финальная верстка выполнялись мной вручную в PyCharm и PowerShell.

# 📝 Список задач (To-Do List)

Современное веб-приложение для управления задачами с кастомным календарем, уведомлениями и сохранением данных.

🔗 **[Посмотреть живое демо](https://romankitaev526-prog.github.io/todo-list/)**

## ✨ Функционал
- ➕ **Добавление задач** с возможностью прикрепить точную дату и время.
- ✅ **Отметка выполнения** (с плавной анимацией зачеркивания).
- 🗑️ **Удаление** задач по одной.
- ⏰ **Кастомный календарь**: удобный выбор даты и времени через выпадающие списки.
- 🔔 **Напоминания**: всплывающие уведомления и нативные уведомления Windows.
- 🔊 **Звуковой сигнал**: прерывистый звук при наступлении времени задачи (с кнопкой «Остановить»).
- 🔴 **Индикация просроченных задач**: задачи с прошедшим временем подсвечиваются красным.
- 🧹 **Массовое удаление**: очистка всех выполненных задач или всего списка одним кликом.
- 💾 **Сохранение данных**: список не пропадает после перезагрузки страницы (LocalStorage).
- 🔍 **Фильтрация**: Все / В процессе / Готово.
- 📱 **Адаптивный современный дизайн** (Glassmorphism, градиенты, анимации).

## 🛠 Стек технологий
- **HTML5** (семантическая верстка)
- **CSS3** (Flexbox, Grid, анимации, Glassmorphism)
- **Vanilla JavaScript** (ES6+, работа с DOM, Web Audio API, LocalStorage)
- **Notification API** (нативные уведомления браузера)

## 🚀 Запуск локально
1. Склонируйте репозиторий:
   git clone https://github.com/romankitaev526-prog/todo-list.git
2. Откройте файл index.html в любом современном браузере.

# Список задач (To-Do List)

Современное веб-приложение для управления задачами на чистом HTML, CSS и JavaScript.

🔗 **[Посмотреть демо](https://romankitaev526-prog.github.io/todo-list/)**

## Функционал
- ➕ Добавление новых задач
- ✅ Отметка выполнения (с анимацией зачеркивания)
- 🗑️ Удаление задач (с анимацией)
- 💾 Сохранение данных в `localStorage` (список не пропадает после обновления)
- 🔍 Фильтрация задач: Все / В процессе / Готово
- 📱 Адаптивный современный дизайн (Glassmorphism, градиенты)

## Стек
- HTML5
- CSS3 (Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- LocalStorage API

## Запуск локально
Просто откройте файл `index.html` в любом браузере.

## AI-инструменты
При разработке использовал Claude 3.5 Sonnet для генерации базовой структуры, логики JavaScript и CSS-стилей. Доработка edge-cases и финальная верстка выполнены вручную в PyCharm.

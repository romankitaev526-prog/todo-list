# To-Do List

Веб-приложение для управления повседневными задачами. Позволяет создавать задачи, назначать сроки, отслеживать выполнение и получать напоминания.

## Демо

[Открыть приложение](https://romankitaev526-prog.github.io/todo-list/)

## Возможности

- Добавление задач.
- Установка даты и времени выполнения.
- Отметка задач как выполненных.
- Удаление отдельных задач.
- Выбор нескольких задач для массового удаления.
- Выбор всех задач в рамках активного фильтра.
- Фильтрация: все задачи, в процессе, выполненные.
- Удаление выполненных задач и очистка списка.
- Автоматическое сохранение задач в LocalStorage.
- Календарь для выбора даты.
- Напоминания о задачах.
- Браузерные уведомления и звуковой сигнал.
- Отображение просроченных задач.
- Адаптивный интерфейс.

## Технологии
